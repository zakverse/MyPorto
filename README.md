# Dzaki Khothir — Portfolio Website

A minimal, professional, and technical personal portfolio website for **Dzaki Khothir** — Informatics Engineering student at Telkom University, focusing on Artificial Intelligence, Machine Learning, and Software Engineering.

Built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Tech Stack

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & Custom SVG Icons
- **Fonts**: Geist Sans & Geist Mono
- **Deployment Target**: Vercel

---

## ✨ Features

- **Anti-Slop Design**: Clean typography, strict visual hierarchy, zero decorative 3D/blobs/particle bloat.
- **Screenshot-Driven Projects**: Real screenshots with an accessible interactive lightbox modal.
- **Verified Repositories**: Direct GitHub links for every featured project (no fake demo buttons).
- **Verified Credentials**: Direct access to authentic certification PDFs (Google AI, Google Data Analysis, Vinix7 internship).
- **Theme Support**: High-contrast Light and Dark mode with local storage persistence and no flash.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop screens with keyboard navigation support.

---

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 24)
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/zakverse/MyPorto.git

# Enter the project directory
cd MyPorto

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
